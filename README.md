# Shrey Jani Portfolio - React Version

A modern, responsive portfolio website built with React and TypeScript, converted from the original HTML version.

## Features

- 🎨 Modern, clean design with dark/light theme toggle
- 📱 Fully responsive layout
- ⚡ Built with React 18 and TypeScript
- 🎯 Smooth scrolling navigation
- 🌟 Intersection Observer animations
- 🚀 Optimized for performance

## Technologies Used

- React 18
- TypeScript
- CSS3 with CSS Custom Properties
- Modern JavaScript (ES6+)

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone https://github.com/Shrey-Jani/TimeGitJenkins.git
cd Portfolio
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm run build` - Builds the app for production
- `npm test` - Launches the test runner
- `npm run eject` - Ejects from Create React App (one-way operation)

## Features

### Theme Toggle

- Supports both dark and light themes
- Remembers user preference in localStorage
- Respects system preference on first visit

### Smooth Scrolling

- Navigation links smoothly scroll to sections
- Back to top functionality

### Responsive Design

- Mobile-first approach
- Optimized for all screen sizes
- Modern CSS Grid and Flexbox

### Performance

- Optimized bundle size
- Lazy loading with Intersection Observer
- Efficient re-renders with React hooks

## Deployment

To build for production:

